# 影像尺寸測量工具

一個基於瀏覽器的影像尺寸測量工具，支援相機校正、自動邊緣偵測與多種量測模式，專為工業檢測與精密量測設計。

## 🌐 線上體驗
**GitHub Pages**: https://mf-studio-lab.github.io/meas-tool/

---

## ✨ 功能特色

### 📏 校正系統
- **水平/垂直尺規**：拖曳兩端點對齊已知尺寸物件
- **圓形尺規**：調整中心與半徑對齊圓形物件
- **即時比例計算**：輸入實際尺寸（mm/µm/cm/inch），自動換算像素比例

### 🔍 自動邊緣偵測
- **降低人為誤差**：使用 Sobel 梯度演算法自動尋找最強邊緣
- **綠色半透明區塊**：視覺化顯示搜尋範圍與偵測結果
- **支援內外輪廓**：矩形與圓形模式可同時偵測外框與內框（壁厚計算）

### 📐 三種量測模式
| 模式 | 適用場景 | 輸出結果 |
|------|----------|----------|
| **兩點距離** | 線性尺寸、孔距、裂縫長度 | 實際距離、像素距離 |
| **矩形** | 矩形零件外框、內框、壁厚 | 寬×高、內框尺寸、壁厚 |
| **圓形** | 圓柱體、孔徑、管徑、壁厚 | 外徑、內徑、壁厚 |

### 📱 跨平台支援
- **桌面版**：側邊工具列，滑鼠操作
- **手機版**：底部工具列，觸控操作，支援後置鏡頭優先

## 🚀 快速開始

### 1. 開啟網頁
直接訪問 [GitHub Pages](https://mf-studio-lab.github.io/meas-tool/) 或用瀏覽器開啟 `Meas_tool.html`

### 2. 允許相機權限
- **HTTPS 環境**（GitHub Pages、Netlify、Vercel）或 **localhost** 才能存取相機
- 手機請使用 HTTPS 網址開啟

### 3. 校正流程
1. 輸入**實際尺寸**與**單位**（如：標準塊 10 mm）
2. 選擇**尺規模式**（線性/圓形）
3. 點擊「顯示半透明尺規」
4. 拖曳尺規控制點，**精確重合**於已知物件邊緣
5. 點擊「完成校正」

### 4. 量測流程
1. 點擊「擷取影像」凍結畫面
2. 選擇量測工具（兩點距離 / 矩形 / 圓形）
3. 在影像上**粗略點選/拖曳**兩點
4. 系統自動顯示**綠色區塊**並計算邊緣
5. 結果面板顯示**實際尺寸**（已換算單位）

## ⌨️ 操作說明

### 校正模式
| 操作 | 說明 |
|------|------|
| 拖曳端點 | 調整尺規長度/角度/半徑 |
| 拖曳尺規本體 | 整體移動位置（線性尺規） |
| 切換模式 | 線性 ⇄ 圓形 下拉選單切換 |

### 量測模式
| 操作 | 說明 |
|------|------|
| 點擊/觸控第一點 | 設定量測起點 |
| 點擊/觸控第二點 | 設定終點，自動觸發邊緣偵測 |
| 「清除量測」 | 重置當前量測 |
| 「重新校正」 | 回到校正模式重新設定比例 |

## 🛠️ 技術架構

- **純前端**：單一 HTML 檔案，無建置步驟，無依賴套件
- **Canvas 2D API**：影像渲染、覆蓋層繪製、互動處理
- **Sobel 算子**：邊緣梯度計算（純 JavaScript 實作）
- **MediaDevices API**：相機存取、後置鏡頭優先
- **響應式設計**：CSS Grid/Flexbox + Media Queries

## ⚠️ 使用限制與注意事項

1. **安全環境要求**：必須在 HTTPS 或 localhost 下運行，否則瀏覽器封鎖相機存取
2. **光線條件**：影像對比度越高，邊緣偵測越準確；建議補光或使用背光
3. **景深影響**：被測物件需在聚焦平面上，失焦會導致邊緣模糊、誤差增大
4. **校正精度**：校正時請盡量拉大尺規範圍、精確對齊，像素誤差會被放大
5. **非專業儀器**：本工具適合**輔助量測、快速檢測、相對比對**，不替代三坐標/CMM/影像量測儀
